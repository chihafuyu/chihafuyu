## 🔭 What I do

- Automate APK fetching, patching, signing, and distribution with **GitHub Actions**.
- Build **PowerShell** tooling for ADB, split-APK installation, and device management.
- Turn complex patch workflows into reusable templates and menu-driven tools.

## 🚀 Featured projects

- **[Chihafuyu-Builder](https://github.com/chihafuyu/Chihafuyu-Builder)** — Automated APK downloading and patching pipeline on GitHub Actions, built as a reusable template.
- **[Chihafuyu-Tool](https://github.com/chihafuyu/Chihafuyu-Tool)** — Menu-driven PowerShell toolkit for patching Android apps and managing ADB installs via Morphe Desktop.
- **[APK-Installer-Uninstaller](https://github.com/chihafuyu/APK-Installer-Uninstaller)** — Lightweight Windows GUI for advanced APK installation, system app debloating, wireless debugging, and logcat.
- **[App-Bundle-Installer](https://github.com/chihafuyu/App-Bundle-Installer)** — Interactive PowerShell CLI for installing `.apkm`, `.apks`, `.xapk`, and `.zip` bundles via ADB.
- **[Universal-PR-Builder](https://github.com/chihafuyu/Universal-PR-Builder)** — GitHub Actions workflow for building Morphe Patcher-based PRs, mainly for unreleased test builds.
- **[Android-SDK-Installer](https://github.com/chihafuyu/Android-SDK-Installer)** — Automates Android SDK core installation without the heavy Android Studio IDE.
